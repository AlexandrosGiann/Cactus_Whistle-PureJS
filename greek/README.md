# Greek word list

`el_lexicon.txt` is generated by `tools/build_greek_lexicon.js` (see the main README) and read by
`greek.js`. It is a derived work of the elspell Greek dictionary, `el_GR.dic` version 0.9
(Steve Stavropoulos and contributors, <http://elspell.math.upatras.gr>), as shipped with
LibreOffice. That dictionary is licensed under MPL 1.1 / GPL 2.0 / LGPL 2.1; its original notice is
in `elspell-README_el_GR.txt`. `el_lexicon.txt` is made available under the same three licences,
at the recipient's choice, not under the Apache License of the rest of this repository.

What changed from the dictionary: the words are lower-cased (names keep their capital), words that
sound the same are merged into one entry, each entry carries a frequency estimate, and the file
ends with a table of word endings (`#grammar`). The frequencies come from `el_common.txt` (written for
this project, Apache-2.0 like the rest) and from word counts over the Greek interface text of a
Windows 11 installation; no text from those files is included.

## Format

```
whistle-greek-lexicon 1 <entries> mix=<weights>
<p><c><rest of word>        one line per sound, sorted by sound
...
#grammar
<word> TAB <ending of the next word> TAB <4 x ln P(ending | word) / P(ending)>
```

`<p>` is how many leading characters the word shares with the previous line and `<c>` is
`-ln p` in steps of 0.25, both written as one character with code 48 + value.
